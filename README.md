# LINEA DUEL

Prototipo web jugable de LINEA DUEL: construye un combatiente, reparte 100 monedas de atributos y lucha contra una unidad controlada por la computadora.

## Funciones de esta primera versión

- Cinco clases: Mago, Ataque, Defensa, Explorador y Tecnología.
- Selección de especialidad y afinidad.
- Distribución exacta de 100 monedas entre Ataque, Defensa, Agilidad, Vitalidad, Suerte y Energía.
- Combate por turnos con ataque básico, habilidad especial, defensa y registro de combate.
- Pasivas de clase y una interfaz adaptable a móvil y escritorio.

## Ejecutar localmente

Abre `index.html` en un navegador moderno. No requiere dependencias ni proceso de compilación.

## Publicar con GitHub Pages

1. Abre **Settings → Pages** en el repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
4. Cuando termine el despliegue, GitHub mostrará la URL del sitio en esa misma sección.

Repositorio: https://github.com/Javenri/linea-duel
